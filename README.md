# Myth Cocoa

Grown rare. Crafted slow.

A premium, performance-driven web interface for Myth Cocoa, developed by Mithra. 
This project encompasses a modern web storefront and branding experience tailored for high-end chocolate production, from farm to bar.

## Technology Stack

- **Framework**: Next.js (React)
- **Styling**: Tailwind CSS
- **Animations**: GSAP & Framer Motion
- **UI Components**: Radix UI

## Development

To start the development server:

```bash
npm run dev
```

Visit `http://localhost:3000` to view the application.
